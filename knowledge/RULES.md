# RULES — knowledge

`knowledge/` содержит только подтверждённые reusable знания.

Добавлять:
- решения повторяющихся проблем;
- diagnostic techniques;
- failure patterns;
- tool limitations;
- verified workarounds;
- compatibility rules.

Не добавлять:
- неподтверждённые hypotheses;
- raw logs;
- полный history iteration;
- копии документации.

## Шаблон knowledge entry
```text
Problem
Symptoms
Root cause
Confirmed environment
Solution
Why it works
Limitations
Related experiments
Sources
```

Тематические файлы создавать только по мере появления реального материала.
